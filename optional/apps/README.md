# Apps

[← Optional](../README.md)

1. Install them:

   ```bash
   brew install --cask brave-browser appcleaner
   ```

2. **Brave:** make it the default browser (System Settings → Desktop & Dock) and sign in to Sync. [Raycast](../raycast/README.md)'s `Hyper B` opens it.
3. **AppCleaner:** removes an app with its leftover files. Nothing to set up.
4. **Amphetamine:** App Store only. Keeps the Mac awake; allow Accessibility when it asks (or run `./setup.sh permissions`).
5. **Dock:** once Brave is installed, run `./setup.sh macos_settings` to add it to the Dock (it was skipped while missing).
